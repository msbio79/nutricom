# 🥗 생체 분자의 탈수 축합 반응 시뮬레이션
> **고등학교 과학 수업용 대화형 시뮬레이션 학습 도구**  
> 탄수화물, 단백질, 지질의 합성 과정에서 물 분자($H_2O$)가 방출되는 **탈수 축합 반응(탈수 반응)**을 직관적으로 관찰하고 실습할 수 있습니다.

---

## 🌟 주요 기능

### 1. 3대 영양소의 탈수 축합 반응 구현
- 🍞 **탄수화물 (Carbohydrates)**:
  - **단당류 3종**: 포도당(Glucose), 과당(Fructose), 갈락토스(Galactose)
  - **결합 프리셋**:
    - 엿당(Maltose): 포도당 + 포도당 + $H_2O$ 방출
    - 설탕(Sucrose): 포도당 + 과당 + $H_2O$ 방출
    - 젖당(Lactose): 갈락토스(β-1번 C) + 포도당(4번 C) → β-1,4 결합 + $H_2O$ 방출
    - 녹말(Starch): α-포도당의 α-1,4 결합 사슬 / 셀룰로오스(Cellulose): β-포도당이 하나씩 뒤집혀 β-1,4 결합한 직선형 사슬
    - 결합 라벨에 α/β 및 결합 위치(1,4 / 1,β-2) 자동 표시
  - **글리코시드 결합(-O-)** 형성 및 하이드록시기(-OH)와 수소(-H)의 결합 분리 과정 시각화
  - **간편 모형**과 **화학 구조식** 실시간 토글 모드

- 🥩 **단백질 (Proteins)**:
  - **20종 아미노산 전체 팔레트**: 글리신(Gly), 알라닌(Ala), 발린(Val), 세린(Ser) 등 20종 아미노산을 자유롭게 추가
  - 카복실기($-COOH$)의 $-OH$와 아미노기($-NH_2$)의 $-H$가 만나 물 분자가 빠져나오며 **펩타이드 결합($-CO-NH-$)** 형성
  - 결합 후에도 펩타이드 결합의 N–H, C=O가 그대로 표시됨
  - 다이펩타이드, 트라이펩타이드, 긴 **폴리펩타이드 사슬** 형성

- 🥑 **지질 (Lipids)**:
  - **글리세롤(Glycerol)** 1분자와 **지방산(Fatty Acid)** 3분자가 반응하여 **3분자의 물($3 H_2O$)**을 방출하며 **중성지방(트라이글리세라이드)** 합성
  - **포화 지방산**(직선형 사슬)과 **불포화 지방산**(이중결합으로 인한 꺾임 구조) 구분 표현
  - **인지질(Phospholipid)**: 글리세롤 1·2번 C에 지방산 2개, 3번 C에 인산기 결합 (친수성 머리 + 소수성 꼬리 2개)
  - **세포막 인지질 2중층(Lipid Bilayer)** 배열 시각화

- 🧪 **자유 모드**:
  - 단당류 3종, 아미노산 20종, 지질 구성 성분(글리세롤·포화/불포화 지방산·인산기)을 한 화면에 자유롭게 불러오기 (프리셋 없음)
  - 같은 종류끼리만 결합하며, 다른 종류를 붙이면 결합하지 않는다는 안내 표시

### 2. 수업 및 전자칠판 최적화 UI/UX
- **시인성 높은 대형 폰트 & 그래픽**: 교실 뒤편에서도 뚜렷하게 보이는 크기와 고대비 컬러
- **다크 모드 / 라이트 모드**: 주변 조명 환경에 맞춰 즉시 전환 가능 (메뉴 상단 버튼)
- **메뉴 접기 / 펼치기**: 화면을 넓게 보고 싶을 때 메뉴를 접을 수 있으며, 접었을 때도 캔버스 상단에 **미니 시뮬레이션 제어기**가 자동으로 나타남
- **단계별 제어 시스템** (사이드바 + 미니 제어기):
  - `[ ▶ 재생 / ⏸ 일시정지 ]`: 결합을 3초 간격으로 자동 진행 (모든 프리셋은 결합 전 상태로 시작)
  - `[ ◀ 이전 ]`: 마지막으로 만든 결합을 가수분해
  - `[ 다음 ▶ ]`: 다음 결합 하나를 형성 (왼쪽부터 차례로)
- **간편 모형 / 화학 구조식** 전환: 간편 모형은 도형과 반응 작용기(OH·H)만 단순하게 표시
- **분자 조작**: 가까이 드래그하면 자석 결합, **결합된 분자 더블클릭(더블탭) → 가수분해**, **단독 분자 더블클릭(더블탭) → 삭제**
- **캔버스 줌 & 팬 (보고 있는 지점 기준)**:
  - 마우스 휠 및 두 손가락 핀치 줌으로 커서 위치를 중심으로 확대/축소 (0.4배 ~ 5배)
  - 캔버스 내 `+`, `-`, `화면 맞춤`(모든 분자가 보이도록 자동 조정) 아이콘 버튼 제공

### 3. 전자칠판용 판서(그리기) 모드
- **독립 판서 레이어**: 필기 중에도 캔버스의 분자 개체가 방해받지 않고 드로잉만 안전하게 입력
- **월드 좌표계 완벽 동기화**: 필기를 한 상태에서 캔버스를 확대, 축소, 이동해도 분자 모형 위에 쓴 글씨와 기호가 정확한 위치에 그대로 유지
- **판서 도구**: 고대비 펜 색상 6종, 굵기 조절(S, M, L), 지우개 모드, 판서 전체 지우기

- **2손가락 핀치/드래그**: 화면 확대/축소 및 화면 이동 (판서 모드에서도 2손가락으로 자유롭게 이동 가능)

## 🚀 깃허브(GitHub Pages) 배포 방법
1. 깃허브에 새 저장소(예: `nutrient-bonding-simulation`)를 생성합니다.
2. `index.html`, `style.css`, `script.js` 3개 파일을 저장소의 루트에 업로드(push)합니다.
3. 저장소의 **Settings** $\rightarrow$ **Pages** 메뉴로 이동합니다.
4. **Branch**를 `main` (또는 `master`)으로 선택하고 `/ (root)`를 지정한 뒤 **Save**를 누릅니다.
5. 몇 초 후 제공되는 URL(예: `https://<깃허브아이디>.github.io/<저장소이름>/`)로 접속하면 스마트폰, 태블릿, PC 어디서나 터치로 바로 실행할 수 있습니다.
